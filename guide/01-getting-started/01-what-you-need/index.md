title: What you need
---

You do not need to understand the full ECS model to start. The first chapters only assume a modern JavaScript/TypeScript project and a browser.

## Prerequisites

- A code editor or IDE with JavaScript/TypeScript support.
- A terminal so you can run package commands and local scripts.
- Node.js and npm for installing packages and running local scripts.
- A browser for the runtime loop.
- Git if you want to work with version control.

## Recommended Setup

Use a current Node.js LTS release if possible. That keeps the examples close to the environment used by most JavaScript projects and avoids surprises with older runtimes.

The guide assumes `npm` in its commands. If you prefer a different package manager, you can usually adapt the examples, but sticking with `npm` makes the early chapters easier to follow.

## What To Verify

Before moving on, check that you can:

- Run `node -v` and `npm -v` without errors.
- Open the project in a browser and reload it while you are developing.
- Clone or update the repository if you plan to follow the contributing chapters later.

Once those basics are in place, continue to the install step.
