---
title: Install the engine
---

With the basics in place, install `wima` in the project you will use for the tutorial.

## New Vite Project

If you are starting from scratch with Vite, create the app first:

```bash
npx create-vite@latest
```

Follow the prompts, then move into the new project root and install `wima` there:

```bash
npm install wima
```

## Existing Project

If you already have a Vite project, you can install the engine directly in that repository:

```bash
npm install wima
```

## Next Step

Once the package is installed, move on to the first app example. That page introduces the imports and the code that starts the engine.
