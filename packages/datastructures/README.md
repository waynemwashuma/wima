---
title: Datastructures
---

`@wimaengine/datastructures` re-exports common dense data-structure primitives from `vifaa`.

## Installation

```sh
npm i @wimaengine/datastructures
```

## Capability Highlights

- Dense list and index-allocation primitives for engine storage.
- Thin core re-export layer over the underlying data-structure library.

## Core Concepts

### Core

The core module is a convenience re-export for the underlying dense data-structure utilities.

## Notes

- Use this package when you need the engine's shared collection primitives without depending on the lower-level library directly.
