---
title: Render Canvas2D
---

`@wimaengine/render-canvas2d` provides the Canvas2D rendering backend for Wima.

## Installation

```sh
npm i @wimaengine/render-canvas2d
```

## Capability Highlights

- Clear-system support for 2D canvas rendering.
- Material helpers and backend-specific core types.
- Plugin, systems, types, and utility exports for integration.

## Core Concepts

### Core

The core modules define the Canvas2D-specific material types and helper functions.

### Systems

The systems modules drive canvas clearing and other 2D rendering work.

### Plugins

The plugins modules register the Canvas2D backend with the engine.

### Utils

The utility module holds small Canvas2D-specific helpers.

## Notes

- This package is the 2D backend counterpart to `@wimaengine/render-core`.
