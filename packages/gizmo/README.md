---
title: Gizmo
---

`@wimaengine/gizmo` provides debug gizmo primitives, settings, and render plugins.

## Installation

```sh
npm i @wimaengine/gizmo
```

## Capability Highlights

- Gizmo core state and configuration.
- Canvas2D systems for debug drawing.
- 2D and 3D plugin entry points for runtime registration.

## Core Concepts

### Core

The core modules define the gizmo state and the settings used by the debug layer.

### Systems

The systems modules render gizmos through the canvas2d debug pipeline.

### Plugins

The plugins modules register the 2D and 3D gizmo integrations with the engine.

## Notes

- `@wimaengine/gizmo` is meant for tooling and debug visualization rather than gameplay systems.
