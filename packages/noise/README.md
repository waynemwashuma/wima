title: Noise
---

`@wimaengine/noise` provides reusable noise-generation helpers.

## Installation

```sh
npm i @wimaengine/noise
```

## Capability Highlights

- Core noise utilities for procedural generation.
- A minimal exported surface for numeric sampling helpers.

## Core Concepts

### Core

The core module exposes the noise functions used by other packages.

## Notes

- Use this package for procedural variation where deterministic noise functions are needed.
