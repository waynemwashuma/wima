---
title: Profiler
---

`@wimaengine/profiler` provides profiling and timer resources for engine performance instrumentation.

## Installation

```sh
npm i @wimaengine/profiler
```

## Capability Highlights

- Runtime profiler state and sampling resources.
- Timer resources for duration tracking.
- Systems that keep profiling data up to date.

## Core Concepts

### Profiler

The profiler resource stores the measurement state used to inspect runtime performance.

### Timer

The timer resource tracks elapsed time and supports lightweight instrumentation.

## Notes

- Use `@wimaengine/profiler` when you want measurements inside the engine rather than external tooling.
